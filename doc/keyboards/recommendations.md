# Ortholinear Split Keyboards for Programming

## Budget Tier ($100–$200)

### Corne (CRKBD) — 42 keys

- Ultra-minimal; forces efficient layer use
- Huge community with shared keymaps
- QMK/ZMK support, hotswap kits ~$130 from [splitkb.com](https://splitkb.com)
- Steep learning curve (no number row — relies entirely on layers)
- Wireless builds possible (nice!nano controllers)
- Best if you want maximum long-term efficiency and are willing to invest in learning layers

### Sofle v2 — 58 keys

- Number row + rotary encoders = gentler transition from standard keyboards
- QMK/ZMK support, kits ~$130–200
- Mostly DIY/kit only; build quality varies by vendor
- Best budget option if you don't want to go full-minimal

## Mid-Range Tier ($365–$425)

### ZSA Voyager — 52 keys

- Ultra-portable, low-profile (Choc switches)
- Magnetic tenting legs + tripod mount
- Hotswap, QMK with [Oryx configurator](https://configure.zsa.io/) (no coding needed)
- Steel plate, carrying case included, 2-year warranty
- ~$365
- Best for: travel/hot-desking programmers who prefer low-profile feel

### ZSA Moonlander — 70 keys

- MX-style hotswap (10 switch choices)
- Articulating thumb cluster, adjustable tenting via wing
- QMK + Oryx configurator, carrying case, 2-year warranty
- 70 keys means less layer dependency while coding
- ~$365
- Best for: easiest transition from a standard keyboard

### Glove80 — 80 keys

- Most keys of any board here (80)
- Concave keywells with sculpted finger columns
- 6 thumb keys per side that are genuinely reachable
- Wireless Bluetooth (4 devices) + USB-C
- Hotswap Choc, ZMK firmware, RGB
- Travel case included
- Rated best split keyboard by RTINGS (Oct 2025)
- ~$384–425
- Best for: programmers wanting max keys + sculpted ergo + wireless

## Premium Tier ($499+)

### Kinesis Advantage360 — 76 keys

- Deepest contoured keywells (best-in-class sculpt)
- Dedicated thumb clusters for Space/Backspace/Enter
- 3 tenting heights
- Pro model has ZMK + Bluetooth (4 devices)
- SmartSet model has simple onboard programming
- 3-year warranty, months-long battery life
- $499–599
- Best for: RSI concerns and deep ergonomic priority

## Top Picks

- **Best overall**: Glove80 — most keys (less layer juggling), wireless, sculpted, strong community consensus
- **Easiest transition**: Moonlander — 70 MX keys feels closest to a normal board
- **Best portable**: Voyager — unmatched travel-friendliness with premium build
- **Best budget entry**: Corne — forces proper layer habits that pay off long-term
- **Best for RSI**: Kinesis Advantage360 — deepest keywell sculpting available

All of these support programmable firmware (QMK or ZMK), which is the real unlock for programming — you can put brackets, arrows, and symbols wherever makes sense for your workflow.
